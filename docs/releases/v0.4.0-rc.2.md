# Playtestr v0.4.0-rc.2

Published and verified as a prerelease. Stable v0.1.0 remains unchanged.
The tag points to frozen source `ae97c62022966cde9699b26169b4dc6ef0a12439`.
The qualified executables and archives were promoted without rebuilding.

This version preserves v1 and opt-in v2 workspaces/reports. It bounds stalled
installer downloads, preserves macOS final terminal output, and retains Linux's
natural-exit EOF optimization. Target applications run with your permissions;
Playtestr is not a sandbox. Go is not required to run the downloaded binary.
