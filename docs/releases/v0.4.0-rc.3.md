# Playtestr v0.4.0-rc.3

Candidate frozen; qualification and publication pending. Stable v0.1.0 remains unchanged.
The shipping source is `07b304bb32aab9d064e7109733c244ab91766899`, built once per
native host with Go 1.26.0. Publication will use those exact qualified archives.

This version corrects selected East Asian Wide/Fullwidth two-column terminal cells,
including cursor movement, overwrite/erase, wrapping, split UTF-8, resize and
alternate-screen behavior. Spec/report v1 and opt-in v2 remain unchanged.
